# MHR — پنل مدیریت شخصی با هسته ترافیک

پنل مدیریت ترافیک اختصاصی MHR؛ کد، طراحی و برند کاملاً مستقل.

## امکانات

- **هسته ترافیک Xray**: اجرا، توقف و ری‌استارت هسته از داخل پنل؛ کانفیگ به‌صورت خودکار از دیتابیس ساخته می‌شود.
- **اینباندها**: پروتکل‌های VLESS / VMess / Trojan با TLS (گواهی self-signed خودکار)، SNI، ECH (کلید سرور با ابزار خود Xray تولید می‌شود) و Fragment.
- **کاربران**: سهمیه حجمی، تاریخ انقضا، فعال/غیرفعال؛ کاربرِ خارج از سهمیه یا منقضی به‌صورت خودکار از هسته حذف می‌شود.
- **آمار زنده**: آپلود/دانلود لحظه‌ای هر کاربر و هر اینباند از API آمار Xray + ثبت مصرف تجمعی در دیتابیس و ریست ماهانه.
- **لینک اشتراک استاندارد**: خروجی base64 برای کلاینت‌ها (`/api/sub?token=…`)، صفحه اشتراک اختصاصی برای هر مشترک (`/?sub=…`) و لینک‌های تکی vless:// / trojan:// / vmess://.
- **لاگ فعالیت**، داشبورد منابع سیستم، پوسته موبایل، تم روشن/تاریک و رابط کامل فارسی (RTL).

## اجرا

```bash
bun install
bun run db:push
bun run core:fetch   # دانلود باینری Xray-core
bun run dev          # http://localhost:3000
```

اولین باز شدن پنل صفحه راه‌اندازی حساب مدیر را نشان می‌دهد.

## استقرار روی Railway

1. مخزن را روی GitHub بگذارید و در Railway از **Deploy from GitHub repo** استفاده کنید (بیلد داکری خودکار از `Dockerfile` انجام می‌شود و باینری هسته در همان بیلد دانلود می‌شود).
2. یک **Volume** با مسیر اتصال `/data` به سرویس اضافه کنید؛ دیتابیس و فایل‌های هسته روی آن ماندگار می‌شوند.
3. متغیر `DATABASE_URL` را روی `file:/data/mhr.db` تنظیم کنید. با تولید دامنه، اتصال HTTPS خودکار است.
4. پورت‌های اینباندها را در Railway با **TCP Proxy** (تنظیمات Networking → TCP Proxy) به‌صورت جداگانه منتشر کنید و دامنه/IP همان را در تنظیمات پنل به‌عنوان «دامنه اشتراک» وارد کنید تا لینک‌های کانفیگ درست ساخته شوند.
5. اگر دامنه عمومی HTTPS دارید، در `src/lib/auth.ts` مقدار `secure` کوکی نشست را `true` کنید.

## یادداشت‌ها

- گواهی‌های TLS به‌صورت خودکار self-signed ساخته می‌شوند؛ برای استفاده عمومی بهتر است گواهی معتبر بگذارید یا پشت لبه TLS (Cloudflare و مانند آن) اجرا کنید.
- کلید عمومی ECH هر اینباند در مسیر `core/runtime/certs/<id>.ech.pub` ذخیره می‌شود تا در رکورد DNS/HTTPS منتشر کنید.
- هسته به‌صورت خودکار هنگام بوت سرور بالا می‌آید (قابل تغییر در تنظیمات پنل).
